# 子ども安全レーダー Androidアプリ 仕様書 v0.4
# TONE非依存・汎用Android版

## 1. 目的

本アプリは、子どもがスマートフォン上で見知らぬ相手と接触し、
連絡先交換、別SNS誘導、秘密化、会う約束、性的要求、脅し、口止めなどに発展する兆候を検知する。

本アプリは、特定キャリアや特定見守りサービスに依存しない。
TONEモバイル、Google Family Link、MDM、端末標準のペアレンタルコントロール等と併用できるが、
それらがなくても単体で基本機能が動作することを目標とする。

## 2. 基本方針

- TONEモバイル専用アプリにはしない
- Android汎用の安全監視アプリとして設計する
- 特定サービス依存のコードを持たない
- 子どもの全入力・全会話を保存するキーロガーにはしない
- 端末内で一次判定を行う
- 高リスク時のみ最小限の証跡を保存する
- 保護者が管理画面で確認・設定できる
- 子ども側にも、必要に応じて安全警告を表示する

## 3. 配布方針

### 3.1 初期方針

初期版はGoogle Play公開を前提にせず、家庭内利用APKとして作成する。

理由:

- 通知監視、IME、画像検査、子どもの安全ログは権限・プライバシー設計が重い
- まず家庭内で実用性を確認する
- 過剰なストア審査対応より、実際の安全確保を優先する

### 3.2 将来方針

将来Google Play公開を検討する場合は、機能を分割する。

候補:

- Safety IME
- Safety Notification Monitor
- Safety Media Checker
- Parent Dashboard

ただし初期実装では単一APKとし、内部モジュールを分ける。

## 4. アプリ構成

単一APK内に以下のモジュールを持つ。

```text
app/
  core/
  notification-monitor/
  safety-ime/
  media-checker/
  local-ai/
  parent-console/
  external-guard/
```

## 5. 各モジュール概要

### 5.1 Core

アプリ全体の基盤。

機能:

* 管理者PIN
* 設定管理
* ログDB
* リスク判定エンジン
* 通知制御
* 権限状態監視
* ローカルAI呼び出し
* データ保持期間管理

### 5.2 Notification Monitor

通知内容を解析する。

対象候補:

* LINE
* SMS
* Gmail
* Discord
* Instagram
* X
* TikTok
* ゲームチャット通知
* その他、管理者が指定したアプリ

取得する項目:

* アプリ名
* 通知タイトル
* 通知本文
* 通知時刻
* 送信者名らしき文字列

制約:

* 通知プレビューが非表示の場合、本文は取得できない
* 既読済みの過去トークは取得できない
* アプリ内部の全履歴を直接読む機能ではない

### 5.3 Safety IME

独自キーボード。

目的:

* 子どもが送信する前の文章を端末内で安全チェックする
* 危険な連絡先交換、秘密化、会う約束、性的要求などを検知する
* 必要に応じて子どもへ警告する
* 高リスク時のみ保護者へ通知・ログ保存する

保存しないもの:

* 全入力履歴
* 全チャット履歴
* パスワード
* 認証コード
* 決済情報
* クレジットカード情報

### 5.4 Media Checker

画像・スクリーンショット・共有画像を検査する。

検知対象:

* QRコード
* LINE IDらしき文字列
* Instagram ID
* Discord招待リンク
* X / TikTok / その他SNSアカウント
* 電話番号
* 住所
* 学校名
* 「追加して」「DMして」などの誘導文

初期版では、画像そのものを保存せず、検知結果のみ保存する。

### 5.5 Local AI

端末内AI判定。

判定レベル:

* Level 0: ルールベース
* Level 1: 軽量分類器
* Level 2: ローカルLLM
* Level 3: クラウドAI、ただし初期状態ではOFF

基本方針:

* ローカルLLMは必須にしない
* 端末性能に応じて有効化する
* 一次判定で怪しい短文だけLLMに渡す
* 常時LLM実行はしない
* LLM非対応端末でも基本機能は動作する

### 5.6 Parent Console

保護者向け管理画面。

機能:

* 管理者PIN設定
* 監視対象アプリ設定
* 検知感度設定
* ログ閲覧
* 高リスクイベント確認
* 権限状態確認
* Safety IME状態確認
* 通知監視状態確認
* Media Checker設定
* ローカルAI設定
* ログエクスポート
* データ削除

### 5.7 External Guard

特定サービスに依存しない、外部制限の確認機能。

目的:

本アプリ単体では、LINE、ブラウザ、SNS、アプリ追加などを完全に制限できない。
そのため、保護者が外部のペアレンタルコントロールや端末設定を併用しているか確認する。

対象例:

* TONEモバイル/TONEファミリー
* Google Family Link
* MDM
* 端末標準のキッズモード
* 手動のアプリ制限
* 手動のインストール制限

このモジュールは、特定サービスと直接連携しない。
チェックリストと運用メモのみを提供する。

## 6. External Guard チェック項目

アプリ内に以下の確認リストを表示する。

### 6.1 アプリ制限

* LINEを許可するか
* オープンチャットを許可するか
* ブラウザを許可するか
* Instagram / X / TikTok / Discordを許可するか
* ゲーム内チャットを許可するか
* Playストアを制限しているか
* 不明なアプリのインストールをOFFにしているか

### 6.2 設定変更対策

* 設定アプリへの自由アクセスを制限しているか
* 通知監視権限を解除できないようにしているか
* IME切り替えを簡単にできないようにしているか
* VPNやプロキシを勝手に追加できないようにしているか
* 新規アプリインストールを制限しているか

### 6.3 連絡手段対策

* 通話先制限を設定しているか
* SMS利用を許可するか
* メール利用を許可するか
* SNSのDMを許可するか
* ゲーム内チャットを許可するか

### 6.4 位置・外出対策

* 位置情報見守りを使っているか
* 予定外移動時に通知されるか
* 外出時のチェックインルールを決めているか
* 家族旅行中や外出中の単独行動ルールを決めているか

## 7. 危険カテゴリ

### 7.1 連絡先交換

検知例:

* QR送って
* ID教えて
* インスタ教えて
* Discord来て
* DMしよう
* 個チャしよう
* 電話番号教えて
* LINE追加して
* ここじゃなくて別で話そう

### 7.2 秘密化

検知例:

* 親に言わないで
* 内緒
* 履歴消して
* 通知切って
* バレないように
* 家族には言わないで
* ここでは話せない

### 7.3 会う約束

検知例:

* 会おう
* 駅で
* 公園で
* トイレの近く
* ホテル
* 何時に来て
* 抜け出して
* 一人で来て
* 家族と別れて来て

### 7.4 性的・自撮り要求

検知例:

* 写真送って
* 自撮り送って
* 見せて
* 体の話
* 動画送って
* もっと見たい
* 服を脱ぐ方向の要求

### 7.5 脅し・支配

検知例:

* 断ったら
* バラす
* 言うこと聞いて
* 誰にも言うな
* 逃げないで
* 消したら怒る
* 返信しないと困る

### 7.6 身元不明リスク

検知例:

* 年齢が不明
* 自称年齢が変わる
* 本名を出さない
* 学校名を言わない
* 顔写真だけ要求する
* 大人かもしれない相手との親密化

## 8. スコア仕様

リスクスコア:

* 0: 問題なし
* 1: 注意
* 2: 要確認
* 3: 高め
* 4: 高リスク
* 5: 即時対応推奨

### 8.1 単独では高リスクにしない例

以下は単独では誤検知が多いため、低〜中リスクに留める。

* 会おう
* 駅
* インスタ
* 写真
* ID
* DM

### 8.2 組み合わせで高リスク化する例

以下の組み合わせはスコアを上げる。

* 連絡先交換 + 秘密化
* 会う約束 + 秘密化
* 会う約束 + 年齢不明
* 会う約束 + 位置異常
* QR交換 + 別SNS誘導
* 自撮り要求 + 秘密化
* 脅し + 画像要求
* 年齢不明 + 1対1で会う約束
* 家族旅行中/外出中 + 予定外移動 + 会う約束

## 9. 通知条件

保護者へ通知する条件:

* risk >= 4
* risk == 3 が短時間に複数回
* 性的要求を検知
* 脅し/口止めを検知
* 連絡先交換 + 秘密化
* 会う約束 + 秘密化
* 会う約束 + 予定外移動
* Safety IMEが無効化された
* 通知監視が無効化された
* 不明なアプリのインストール許可がONになった可能性
* 新しいSNS/チャットアプリが検出された

## 10. 子ども側警告

送信前または検知時に、子どもへ警告を表示する。

例:

* 知らない人にQRコードやSNS IDを送るのは危険です
* 親に内緒で会う約束をするのは危険です
* 写真や自撮りを送る前に保護者に相談してください
* 連絡先を別アプリへ移すよう言われたら注意してください
* 不安な時は家族に相談してください

重大リスクでは、子ども側警告と同時に保護者へ通知する。

## 11. ログ仕様

### 11.1 保存するもの

* 検知日時
* 検知元

  * 通知
  * IME
  * 画像
  * QR
  * システム状態
* アプリ名
* 危険カテゴリ
* リスクスコア
* 最小限の抜粋
* 判定理由
* 保護者確認状態

### 11.2 保存しないもの

* 全チャット履歴
* 全入力履歴
* パスワード
* 認証コード
* 決済情報
* 通話録音
* 画像そのもの
* 常時スクリーン録画

### 11.3 ログ保持

初期値:

* 高リスクログ: 90日
* 中リスクログ: 30日
* 低リスクログ: 7日
* 保護者が手動削除可能

## 12. Safety IME 固定方針

通常のAndroidアプリ単体では、独自IMEだけを完全強制しない。

方針:

* Safety IMEを標準入力方式として設定する
* Safety IMEが無効化されたら検知する
* Safety IME以外が使われた可能性を検知する
* 保護者へ通知する
* 外部制限機能により設定アプリやIME切替を触りにくくする
* Device Owner/DPCが使える場合のみ、許可IME制限を検討する

注意:

OS標準IMEを完全に消すことは目標にしない。
完全強制ではなく、検知・警告・外部制限の組み合わせで実用性を高める。

## 13. 端末性能別AIモード

### 13.1 Basic Mode

全端末向け。

機能:

* ルールベース判定
* 通知監視
* Safety IME
* QR検知
* SNS ID検知
* ローカルログ

### 13.2 Standard Mode

中性能端末向け。

機能:

* Basic Mode
* 軽量日本語分類器
* 誤検知低減
* 類似表現検知

### 13.3 Local LLM Mode

高性能端末向け。

機能:

* Standard Mode
* ローカルLLMによる短文文脈判定
* JSON形式のリスク判定
* 高リスク候補のみ推論

### 13.4 Cloud Assist Mode

任意。

* デフォルトOFF
* 保護者が明示的に許可した場合のみ使用
* 個人情報を送る前に警告
* 送信内容を最小化する

## 14. サイドロード運用

### 14.1 インストール手順

1. 保護者が端末の制限を一時解除する
2. APKを端末に配置する
3. APKインストール元アプリに「不明なアプリのインストール」を一時許可する
4. 本アプリをインストールする
5. インストール元アプリの許可をOFFに戻す
6. 端末の制限を再度ONにする
7. 本アプリを起動する
8. 管理者PINを設定する
9. 通知監視をONにする
10. Safety IMEを有効化する
11. 必要な権限を許可する
12. External Guardチェックリストを確認する

### 14.2 更新手順

* 同じ署名キーでAPKを署名する
* 既存ログを保持する
* 更新後に権限状態を再診断する
* 重要権限が外れていれば保護者に警告する

## 15. Google Play公開時の分割案

将来Google Play公開を検討する場合は、単一アプリを以下に分割する。

### 15.1 Safety IME

* 入力前警告に特化
* 全文保存なし
* 高リスクのみ通知
* IME利用時の明確な説明を表示

### 15.2 Safety Notification Monitor

* 通知監視に特化
* 通知本文取得の制約を明示
* 常時監視中であることを明示

### 15.3 Safety Media Checker

* QR/画像チェックに特化
* 自動常時監視ではなく、選択画像検査を基本にする
* 画像本体を保存しない

### 15.4 Parent Dashboard

* 親の確認専用
* ログ閲覧
* 設定変更
* 通知受信
* 子アプリ状態確認

## 17. MVP受け入れ条件

### 17.1 管理

* 管理者PINを設定できる
* 娘本人が設定変更できない
* 保護者が検知感度を変更できる
* 保護者がログを確認できる

### 17.2 通知監視

* LINE等の通知を検知できる
* 通知本文が取得できる場合はリスク判定できる
* 通知本文が取得できない場合も通知発生ログを残せる
* 高リスク時にログ保存できる

### 17.3 Safety IME

* 独自IMEを有効化できる
* 入力文を送信前に判定できる
* 全文保存しない
* 高リスクのみ最小限ログを保存する
* Safety IMEが無効化されたら警告する

### 17.4 リスク判定

* 連絡先交換を検知できる
* 秘密化を検知できる
* 会う約束を検知できる
* 自撮り要求を検知できる
* 脅し/口止めを検知できる
* 単語単体では過剰通知しない
* 危険な組み合わせではスコアを上げられる

### 17.5 External Guard

* 外部制限チェックリストを表示できる
* TONE、Family Link、MDMなどに依存しない文言になっている
* 保護者が運用状態を確認できる

### 17.6 プライバシー

* 全チャット履歴を保存しない
* 全入力履歴を保存しない
* パスワード・認証コードを保存しない
* 画像そのものを保存しない
* ログ削除ができる
